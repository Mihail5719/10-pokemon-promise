# ⚡ Pokémon Ability — цепочки промисов

Интерактивное веб-приложение, которое получает данные о покемоне из PokéAPI
с помощью цепочек промисов (`.then() / .catch()`): загружает покемона,
находит его первое умение и выводит описание умения на английском языке —
в консоль и в карточку на странице.

## 🎯 Назначение проекта

Домашнее задание по теме «Асинхронный JavaScript»: переработка предыдущей
версии кода с `XMLHttpRequest` и вложенными колбэками на `fetch`
и плоские цепочки промисов с корректной обработкой ошибок.

## ✨ Основные возможности

- 🐾 **Загрузка покемона:** запрос к `https://pokeapi.co/api/v2/pokemon/{name}`
  (по умолчанию — Ditto, можно ввести любого покемона в форму).
- 🧬 **Первое умение:** из данных покемона извлекается ссылка
  `abilities[0].ability.url` и выполняется второй запрос.
- 🇬 **Описание на английском:** поиск записи с `language.name === 'en'`
  в `effect_entries` умения.
- 🖥️ **Вывод в консоль:** текст умения дублируется через `console.log()`.
- 🎨 **Карточка на странице:** изображение, имя покемона, название умения
  и его описание.
- 🌀 **Индикатор загрузки:** спиннер показывается на время запросов.
- 🛡️ **Обработка ошибок:** единый `.catch()` для всей цепочки — сетевые
  сбои, HTTP 404/500, невалидный JSON, отсутствие описания.

## 🛠 Технологии

- **HTML5** (семантическая разметка)
- **CSS3** (градиенты, анимация спиннера, адаптивность)
- **JavaScript (ES6+)** — `fetch`, цепочки промисов, `throw new Error()`
- **PokéAPI** — открытый REST API с данными о покемонах

🚀 Как запустить
Откройте папку проекта.
Запустите index.html в браузере (удобнее всего — через Live Server).
Введите имя покемона (например, pikachu) и нажмите «Загрузить».
Для работы необходим доступ в интернет — данные приходят из PokéAPI.
